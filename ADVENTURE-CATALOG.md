# Adventure skill catalog

| Skill | Recommended daily practice | 30-day practice | Goal |
|---|---:|---:|---|
| Morse code | 30 min | 15 h | Read and send simple messages using Morse code. |
| Typing | 20 min | 10 h | Build faster, more accurate touch typing. |
| Drawing nature | 30 min | 15 h | Practice observing and sketching plants, trees, and landscapes. |
| Public speaking | 25 min | 12.5 h | Practice clear speaking, structure, and delivery. |
| Chess | 45 min | 22.5 h | Build tactical awareness and basic chess patterns. |
| Cooking | 45 min | 22.5 h | Learn repeatable kitchen skills and a few reliable meals. |
| French | 60 min | 30 h | Build a useful beginner French foundation. |
| Spanish | 60 min | 30 h | Build a useful beginner Spanish foundation. |
| Wrestling | 60 min | 30 h | Learn coached wrestling movement and fundamentals safely. |
| Programming | 90 min | 45 h | Build small programs and understand core programming ideas. |

The daily practice figures are product targets for the 30-day challenge, not claims of guaranteed mastery. Adventure filters and weights these skills from the user's own daily time estimate.
