# Daheer asset licensing ledger

## Original Daheer vectors
The refreshed inline icons and the vector assets in `src/assets/vectors/` are original Daheer artwork released under **CC0 1.0 Universal**.

## Existing ambient audio
The two existing ambient files were kept from the prior build only because their individual source entries were permissive: `blanket-stream.ogg` was listed as CC0 and `blanket-coffee-shop.ogg` as public domain in Blanket's sound licensing document. Keep these notes with the distributed build. Do not assume other Blanket project files or sounds are covered by these entries.

## Fonts and branding
Bundled Latin fonts, Thmanyah fonts, and Daheer brand assets are not re-licensed by this file. Preserve their source licenses/permissions when redistributing.


## Flowers Kingdom (desk clock font)
`src/assets/fonts/latin/FlowersKingdom.ttf` - "Flowers Kingdom" by Imagex (2016). The font's own licence field says **"Free for personal use ONLY"**.
It was supplied by the project owner for personal use. **Before distributing Daheer publicly or commercially, buy a commercial licence from the
designer or replace this font** (the clock falls back to the UI font if the file is removed).
